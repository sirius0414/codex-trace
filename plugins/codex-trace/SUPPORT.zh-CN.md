# Codex Trace 支持

[English](SUPPORT.md) | [简体中文](SUPPORT.zh-CN.md)

Codex Trace 由 Codex Trace contributors 独立维护。0.2.2 的主要安装渠道为 GitHub 仓库市场 `codex-trace-community`，完整说明见 [社区安装指南](INSTALL.zh-CN.md#社区市场安装)。

- 项目主页：[sirius0414/codex-trace](https://github.com/sirius0414/codex-trace)
- 安装与恢复：[INSTALL.zh-CN.md](INSTALL.zh-CN.md)
- Windows 支持边界：[WINDOWS.zh-CN.md](WINDOWS.zh-CN.md)
- 普通问题反馈：[GitHub Issues](https://github.com/sirius0414/codex-trace/issues)
- 私密漏洞报告：[SECURITY.zh-CN.md](SECURITY.zh-CN.md)
- 数据保存与清理：[PRIVACY.zh-CN.md](PRIVACY.zh-CN.md)
- 使用说明与许可：[TERMS.zh-CN.md](TERMS.zh-CN.md)、[LICENSE](LICENSE)

提交问题时，请附操作系统、Codex 桌面应用/CLI 版本、uv／Python 版本、插件版本、安装渠道、复现步骤、预期与实际结果，以及已脱敏的错误摘要。导出问题请说明界面显示的是等待、结果未确认、失败还是已校验；保留原请求供本机核对，不要为排查反复创建新的导出。

仓库当前为 **PRIVATE**。GitHub Issues 遵循仓库访问权限；仓库可见性变化后，提交的内容可能公开。请按可能被分享的材料处理问题内容。请勿上传凭据、真实任务正文、完整原始会话或未经检查的导出 ZIP；路径、标题、日志和截图也可能包含个人信息。可优先用合成记录复现。安全或隐私漏洞请按 [SECURITY.zh-CN.md](SECURITY.zh-CN.md) 私密报告，并遵循私密入口不可用时的处理说明，不在公开问题中披露敏感细节。项目未承诺固定回复时限或服务等级。

此处及插件清单中的 GitHub URL 指向本仓库及所声明的 `main` 分支。当前安装者与阅读者需要 Git／仓库读取权限；这些链接不代表公开可用的承诺。维护者须推送相应文档，并验证目标受众能够访问；本地存在文件不表示远端页面已经可用。社区市场是否可用、Release 状态须以实际远端记录为准。未来若申请 OpenAI 公共目录，公开 URL、开发者身份认证、提交权限和平台审核将分别确认。
